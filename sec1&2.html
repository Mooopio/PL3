1 What is F#? (Intro)

اللي في السلايد

  • Originally developed at the University of Oxford (حسب السلايد).
  • Deeply integrated with functional programming paradigms.
  • Part of .NET Family: جزء من الـ .NET ecosystem، وده بيدّي smooth interoperability مع لغات .NET التانية زي C# و VB.NET.

الشرح خطوة بخطوة

  1. Functional programming يعني بتبني البرنامج من functions بتاخد input وترجّع output (زي الدوال في الرياضة)، ومش بتعتمد على تغيير variables طول الوقت.
  2. F# مصممة عشان الأسلوب ده يبقى هو الطبيعي فيها: كل حاجة تقريبًا expression بيرجّع value.
  3. .NET family يعني كل اللغات دي بتتحول لنفس الـ intermediate code وبتشتغل على نفس الـ runtime، فينفع class library مكتوبة بـ C# تتستخدم من F# والعكس.
Analogy .NET زي عيلة كبيرة: مصري وسعودي وشامي كلهم بيتكلموا لهجات مختلفة بس بيفهموا بعض لأن الأساس العربي واحد. C# و F# و VB.NET لهجات، والـ .NET هو الأساس المشترك (interoperability).
Exam tip سؤال تعريف F#: اذكر 3 حاجات — (1) functional language (2) أصلها Oxford حسب السلايد (3) جزء من .NET وبتتعامل مع C# و VB.NET.
2 F# vs C#

اللي في السلايد

F#C#
Fully Functional Language: مصممة أساسًا كـ functional، بتركز على استخدام functions وبتدعم pure functions و lazy evaluation (حسب السلايد). Multi-Paradigm Language: بتدعم OOP و functional مع بعض، بس مش بنفس عمق F#.

نفس الدالة في اللغتين

// F#
let add x y = x + y
let result = add 3 5  // 8
// C#
using System;

class Program
{
    static void Main()
    {
        Func<int, int, int> add = (x, y) => x + y;
        int result = add(3, 5);  // 8
    }
}

الشرح

  • في F# السطرين كفاية: مفيش class ولا Main ولا using ولا return ولا types مكتوبة (type inference).
  • في C# محتاج class + Main + Func<int,int,int> (delegate type: 2 int inputs، 1 int output) + lambda (x, y) => x + y.
  • النتيجة واحدة (8) لكن F# أقصر وأقرب للـ math.
Analogy F# زي جرّاح قلب متخصص (functional بس وعميق)، و C# زي دكتور عام شاطر (يعمل OOP و functional بس مش لأخر عمق).
Trap متقولش إن C# مبتدعمش functional. الصح: بتدعمه بس مش بالكامل زي F#.
3 Installation & Setup (5 steps)

الخطوات بالترتيب

  1. Install .NET SDK — حمّله من الـ official .NET website. بعد التثبيت اتأكد من الـ terminal: 
    dotnet --version
    لو طلع رقم version يبقى تمام.
  2. Install Visual Studio Code — من الـ official VS Code website.
  3. Install the Ionide-F# Extension — ده اللي بيدّي لـ VS Code دعم F# (syntax highlighting, IntelliSense, errors).
  4. Verify the Installation — اعمل ملف جديد بامتداد .fsx (F# Script) واكتب: 
    let add x y = x + y
printfn "%d" (add 2 3)
    واضغط F5 لتشغيل الكود في VS Code (حسب السلايد). المفروض يطبع 5.
  5. Create a New F# Project — افتح VS Code Terminal (Ctrl + `) ونفّذ: 
    dotnet new console -lang "F#" -o MyFSharpApp
cd MyFSharpApp
dotnet run
    ده بيعمل ويشغّل basic F# console application.

4 Variables in F# (let & immutability)

اللي في السلايد

  • الـ variables بتتعرّف بكلمة let (بعكس لغات كتير تانية).
  • الـ variables immutable (constant) by default: أول ما تدّيها value متقدرش تغيّرها.
let x = 10
printfn "The value of x is: %d" x

الشرح

  1. let x = 10 مش "assignment" بالمعنى المعتاد، دي binding: بتربط الاسم x بالقيمة 10 للأبد.
  2. printfn بتطبع بـ format: %d = integer، وبعدها القيمة x.
  3. لو كتبت بعدها x <- 20 هيطلع compile error لأن x مش mutable.
Analogy الـ let زي رقمك القومي في البطاقة: اتكتب بحبر ومينفعش تمسحه. إنت ممكن تطلّع بطاقة جديدة، بس مش هتعدّل القديمة.
Why immutable? الكود أأمن وأسهل في التتبّع: القيمة اللي شفتها في أول الدالة هي نفسها في آخرها، ومفيش حد يغيّرها من ورا ضهرك.
5 Mutable Variables

اللي في السلايد

لو محتاج variable قيمتها تتغيّر، استخدم الكلمة mutable.

let mutable y = 5
y <- 10  // Reassigning a new value to the mutable variable y

Example 1 — Immutable variable + new calculated value

let baseValue = 20
let newValue = baseValue + 5

baseValue فاضلة 20 زي ما هي، و newValue = 25 (قيمة جديدة اتحسبت من القديمة بدل ما نعدّل القديمة).

Example 2 — Mutable variable in a loop

let mutable counter = 0
for i in 1..10 do
    counter <- counter + 1

بعد اللوب counter = 10 (زوّدنا 1 عشر مرات).

Example 3 — Mutable variable inside a function

let calculate x =
    let mutable y = x + 10  // y is mutable
    y <- y * 2              // changing the value of y
    y                       // returning the modified y

let result = calculate 5
printfn "The result is: %d" result

Trace: x=5 → y = 15 → y = 30 → بيرجّع 30 → يطبع The result is: 30.

Two operators — لا تخلطهم = يعمل binding أول مرة (let y = 5) أو comparison جوه expression (if n = 0). <- بيعمل reassignment لـ mutable فقط.
Analogy الـ mutable زي السبورة الوايت بورد: تكتب وتمسح وتكتب تاني. الـ let العادي زي حبر الشهادة.
Trap الـ let وحدها بتعمل constant حتى لو كتبت <- بعدها → error. لازم mutable الأول.
6 Functions (immutability, type annotation, return, purity)

أ) Functions are immutable

السلايد: once a function is defined, it cannot be reassigned or modified.

let multiply x = x * 2

// Trying to change the function definition will cause an error
// multiply <- fun x -> x + x  // This will result in an error

let result = multiply 5
printfn "The result is: %d" result

الناتج: 10. السطر المعلّق هيعمل error لأن multiply اتعرّفت بـ let مش let mutable.

ب) Note: Type annotation & type inference

لو حددت type فهو بييجي بعد اسم الـ parameter ومفصول عنه بـ colon :. ولو سبته، الـ compiler بيستنتجه (inferred).

let f (x: int) = x + 1

هنا x بتتفهم int لأن 1 هو int (حتى لو ماكتبناش : int).

Analogy الـ compiler زي دكتور شاطر: يبصّ على الكارنيه ويعرف إنك طالب هندسة من غير ما تقوله. شاف 1 جنب x فعرف إن x رقم صحيح.

ج) Pure function example

let add x y = x + y
  • Pure function: نفس الـ input يرجّع دايمًا نفس الـ output، ومبتغيّرش حاجة برّه (no side effects).
  • F# functions بترجّع تلقائيًا قيمة آخر expression من غير كلمة return.
  • الـ arguments بتتفصل بمسافات (add 3 5) مش بأقواس وفواصل.
Analogy الـ pure function زي ماكينة عصير القصب: تدخل قصب (input) يطلع عصير (output) وكل مرة نفس النتيجة، ومبتغيرش حاجة في المحل.
Trap في F# مفيش return. لو كتبتها كـ keyword هتتعامل كـ identifier مش معروف. آخر سطر هو الناتج.
7 Scope in F#
let calculate x =
    let y = x + 10
    y * 2

let result = calculate 5
printfn "result is %d " result

Output: result is 30 (لأن y = 15 ثم 15 × 2 = 30).

لما نحاول نستخدم y برّه الدالة

printfn "The value of y is: %d" y

Output (error):

F# Compiler for F# 4.0 (Open Source Edition)
Freely distributed under the Apache 2.0 Open Source License
/HelloWorld.fs(18,33): error FS0039: The value or constructor 'y' is not defined

الشرح

  • y متعرّفة جوه الدالة calculate فقط → local scope.
  • برّه الدالة الـ compiler مش شايف y → error FS0039: The value or constructor 'y' is not defined.
  • الـ indentation (المسافات) هي اللي بتحدد أي سطور تبع الدالة.
Analogy الدالة زي أوضة نوم مقفولة: اللي جواها (y) محدش يشوفه من الصالة. اللي بيطلع برّه بس هو اللي الدالة ترجّعه (y * 2).
Exam tip الاسم "FS0039" ومعنى الرسالة بيتسألوا كتير: not defined = برّه الـ scope.

Analogy الـ list زي كرتونة بيض (كله بيض). الـ tuple زي شنطة مدرسة فيها كتاب وقلم وسندوتش (حاجات مختلفة). الـ unit زي إنك تقفل النور: عملت فعل ومفيش حاجة رجعتلك.

Format specifiers مع printfn: %d int · %f float · %s string · %b bool · %A أي نوع.
9 Control Flow & If-else

الـ Control flow في F# بيشمل:

  • Conditional statements زي if-else
  • Loops زي for و while
  • Pattern matching بـ match
  • Recursion للدوال اللي بتنادي نفسها (self-referencing functions)

If-else

if x > 0 then
    printfn "x is positive"
elif x < 0 then
    printfn "x is negative"
else
    printfn "x is zero"
  • الكلمات: if … then / elif … then / else. لاحظ elif مش "else if".
  • مفيش أقواس حوالين الشرط ولا curly braces؛ الـ indentation بتحدد الـ block.
  • الـ if في F# هي expression: ممكن ترجّع value، وبالتالي كل الفروع لازم تبقى من نفس الـ type.
Analogy الـ if-else زي الأمن على البوابة: لو معاك كارنيه ادخل، لو معاك تصريح (elif) ادخل من بوابة تانية، غير كده (else) ارجع.
10 Loops (for & while)

For loop

for i in 1..5 do
    printfn "i = %d" i

بيطبع i = 1 لحد i = 5 (الـ range 1..5 inclusive: بيشمل 5). الـ i هنا مش محتاجة mutable لأنها بتتربط بقيمة جديدة في كل لفة.

While loop

let mutable i = 0
while i < 5 do
    printfn "i = %d" i
    i <- i + 1

بيطبع i = 0 لحد i = 4 (لأن الشرط i < 5). هنا لازم mutable لأننا بنحدّث i بنفسنا بـ i <- i + 1؛ ولو نسيت التحديث هيبقى infinite loop.

forwhile

11 Pattern Matching

Example 1

let describeNumber x =
    match x with
    | 0 -> "Zero"
    | 1 -> "One"
    | _ -> "Other"

Example 2

let describeDay day =
    match day with
    | "Monday" | "Tuesday" | "Wednesday" | "Thursday" | "Friday" -> "Weekday"
    | "Saturday" | "Sunday" -> "Weekend"
    | _ -> "Not a valid day"

الشرح

  • match x with يبدأ المطابقة. كل سطر | pattern -> result هو case.
  • الـ cases بتتجرّب من فوق لتحت و أول واحد يطابق هو اللي بيتنفذ.
  • _ هو wildcard بيطابق أي حاجة (default / catch-all) ولازم يبقى آخر case.
  • الـ | بين patterns جوه نفس case معناها OR: "Monday" أو "Tuesday" … كلهم نفس النتيجة.
  • Results: describeNumber 0 = "Zero"، describeNumber 7 = "Other"، describeDay "Sunday" = "Weekend"، describeDay "Funday" = "Not a valid day".
Analogy زي ماكينة فرز الجوابات في مكتب البريد: كل جواب بيتفحص ويروح للصندوق المناسب، و _ هو صندوق "أخرى" للي ملوش مكان.
Trap لو حطيت _ في الأول، هتبلع كل الحالات وباقي الـ cases عمرها ما تتنفذ.
12 Recursion
let rec factorial n =
    if n = 0 then 1
    else n * factorial (n - 1)

الشرح

  • rec ضرورية: بتقول للـ compiler إن الدالة هتنادي نفسها.
  • Base case: n = 0 → ترجّع 1 (هو اللي بيوقف الـ recursion).
  • Recursive case: n * factorial (n - 1).

Trace: factorial 3

factorial 3
= 3 * factorial 2
= 3 * (2 * factorial 1)
= 3 * (2 * (1 * factorial 0))
= 3 * (2 * (1 * 1))
= 6
Analogy الطابور: كل واحد بيسأل اللي قدامه "إنت كام؟" وبيضرب إجابته في رقمه. أول واحد في الطابور (0) بيقول "1" وبيبدأ الجواب يرجع لورا.
Traps (1) نسيان rec → error. (2) نسيان الـ base case → infinite recursion. (3) هنا = معناها مقارنة.

📄 1-Page Ultra-Fast Sheet

  • F# = functional language, .NET family, interop with C# / VB.NET (Oxford per slides).
  • F# vs C#: F# fully functional (pure functions, lazy) · C# multi-paradigm (OOP + functional, less fully).
  • Install: .NET SDK (dotnet --version) → VS Code → Ionide-F# → verify .fsx + F5 → dotnet new console -lang "F#" -o MyFSharpApp, cd, dotnet run.
  • let = immutable · let mutable + <- = changeable.
  • Functions: immutable · param type (x: int) else inferred · auto-return last expression · pure = same in/same out.
  • Scope: inside function only. Outside → error FS0039: The value or constructor 'y' is not defined.
  • Types: int, float, string, bool, list [1; 2], tuple ("Alice", 30), unit ().
  • Control: if / elif / else · for 1..5 · while (mutable) · match / _ · let rec.
  • printfn: %d int.
