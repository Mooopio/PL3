  • for loop على Map: السلايد بيستخدم for (key, value) in myMap do. لو الـ compiler اشتكى، الصيغة الشائعة البديلة for KeyValue(key, value) in myMap do. اكتب اللي في السلايد في الامتحان.
  • Inline: let inline ممكن تخلّي الدالة تشتغل على int و float مع بعض (generic)، وده السبب إن add 3 5 و add 10.0 5.0 الاتنين شغالين في السلايد.
  • Output format للـ %A: بيطبع structured representation (للـ records والـ lists بيكون مفصّل ومرتب)، فمتحفظش الشكل الحرفي بالمسافات؛ احفظ المحتوى.
1 Data Types Overview & Printing

اللي في السلايد

  • Basic Types: int, float, String, bool.
  • Compound Types: List, Array, Tuple, Set, … (وغيرهم).
  • Printing: استخدم printfn "%A" لطباعة أي type.
  • Note: printfn أو printf — الـ n في آخر printfn معناها new line.

الشرح

  • Basic (primitive) types = قيمة واحدة بسيطة. Compound types = بتجمع أكتر من قيمة جوه حاوية واحدة (collections / structures).
  • الـ format specifiers اللي عدّت علينا: %d int · %s string · %b bool · %f float · و %A = أي نوع (list, tuple, record, map …).
printfn "Hello"      // prints Hello + new line
printf  "Hello"      // prints Hello, NO new line
printfn "%A" [1; 2; 3]
Analogy الـ printf زي إنك تكتب في الورقة من غير ما تنزل سطر. الـ printfn زي ما تضغط Enter بعد الكتابة (n = new line). والـ %A زي "شنطة مفاجآت": أي حاجة تحطها جواها بتتطبع.
Exam tip "ليه n في آخر printfn؟" → new line. "إزاي أطبع list أو tuple؟" → %A.
2 Arrays & Lists

Arrays (اللي في السلايد)

  • Definition: Fixed-size collection of elements of the same type.
let numbers = [| 1; 2; 3; 4 |]

Lists (اللي في السلايد)

  • Definition: Flexible-size collection, similar to a linked list.
let numbers = [1; 2; 3; 4]

3 Sets

اللي في السلايد

  • Definition: Unordered collection of unique elements.
let mySet = set [1; 2; 3; 4]
let mySetDirect = set {1; 2; 3; 4}

Accessing Values (add / remove)

let mySet = set [1; 2; 3; 4]
let updatedSet = mySet.Add(5)

let mySet = set {1; 2; 3; 4}
let smallerSet = mySet.Remove(3)

Contains

let mySet = set [1; 2; 3; 4]
let hasTwo = mySet.Contains(2)
let hasSeven = mySet.Contains(7)

printfn "Does the set contain the number 2? %b" hasTwo
printfn "Does the set contain the number 7? %b" hasSeven

Output:

Does the set contain the number 2? true
Does the set contain the number 7? false

الشرح

  • Unique يعني لو حطيت نفس الرقم مرتين بيتخزن مرة واحدة.
  • .Add(5) و .Remove(3) بيرجّعوا set جديدة والأصلية تفضل زي ما هي (immutable behavior). عشان كده بنخزّن النتيجة في updatedSet و smallerSet.
  • .Contains(x) بترجّع bool (true / false) وبتتطبع بـ %b.
Analogy الـ Set زي قايمة الحضور في المحاضرة: الطالب اسمه بيتسجل مرة واحدة بس حتى لو مضى مرتين. و Contains = "فلان حاضر؟" → true/false.
Trap mySet.Add(5) لوحدها مش بتغيّر mySet! لازم تاخد النتيجة في variable.
4 Records

اللي في السلايد

  • Description: Record = data structure بيحمل مجموعة named fields، وكل field ممكن يكون من type مختلف.
  • Advantages: مناسب لتنظيم الـ data المعقدة لأن كل field له اسم واضح، فسهل الفهم والاستخدام.
type Person = { Name: string; Age: int; Job: string }

let person = { Name = "Ali"; Age = 25; Job = "Engineer" }

printfn "%A" person

تفكيك الكود

  1. type Person = { … } بتعرّف الشكل (type). جوه الـ definition بنكتب FieldName: type وبنفصل بـ ;.
  2. let person = { Name = "Ali"; … } بتعمل instance. هنا بنكتب FieldName = value (علامة = مش :).
  3. printfn "%A" person بتطبع الـ record بكل fields (Name = "Ali", Age = 25, Job = "Engineer").
Analogy الـ Record زي استمارة بيانات: خانة "الاسم" وخانة "السن" وخانة "الوظيفة". كل خانة ليها عنوان فواضح فين كل معلومة.
Trap في الـ type definition بنستخدم : (Name: string)، وفي إنشاء القيمة بنستخدم = (Name = "Ali").
5 Tuples (definition, types, paired data)

اللي في السلايد

  • الـ tuple = ordered collection of values، و عدد العناصر ثابت وقت الإنشاء (fixed when it is created).
  • General syntax:
let tupleName = (value1, value2, ..., valueN)

Types of Tuples

  1. Simple Tuple: two values of same or different types. 
    let coordinates = (3, 5)
// Represents an x-y coordinate with x = 3 and y = 5
  2. Mixed Types: different types of values. 
    let person = ("Alice", 25, true)
// Represents a person's name, age, and active status
  3. Nested Tuples: tuples جوه tuples. 
    // A nested tuple that contains two tuples
let nestedTuple = ((1, 2), ("Alice", true))

// Explanation:
// The outer tuple contains:
// 1. The first element is another tuple (1, 2)
// 2. The second element is another tuple ("Alice", true)

Handling Paired Data

لما القيم ليها ترتيب أو ازدواج طبيعي زي الإحداثيات (x, y) أو أجزاء التاريخ (day, month, year) فالـ tuple مناسب.

let coordinates = (3, 5)
// Represents an x-y coordinate with x = 3 and y = 5

let date = (22, 10, 2024)  // (day, month, year)
let (day, month, year) = date
printfn "Date: %02d-%02d-%04d" day month year

Output: Date: 22-10-2024

الشرح

  • let (day, month, year) = date اسمها destructuring (unpacking): بتفك الـ tuple لـ 3 variables مرة واحدة.
  • %02d = integer على الأقل خانتين ويتملي بأصفار من الشمال (يعني 5 تبقى 05). %04d = أربع خانات (2024).
  • الـ tuple عدد عناصره ثابت وعناصره ممكن تبقى أنواع مختلفة.
Analogy الـ tuple زي تذكرة قطر: (رقم القطر، رقم العربية، رقم الكرسي) — ترتيب ثابت وكل مكان له معنى، بس مفيش أسماء مكتوبة. والـ nested زي شنطة جواها شنطة صغيرة.
6 Accessing Nested Tuples (pattern matching vs fst/snd)
let nestedTuple = ((1, 2), ("Alice", true))

الطريقة 1: Pattern matching (الأوضح والأشهر)

السلايد: pattern matching is the most common and clear way للوصول لقيم الـ nested tuple.

let ((x, y), (name, isActive)) = nestedTuple

// Now x = 1, y = 2, name = "Alice", isActive = true
printfn "X: %d, Y: %d" x y
printfn "Name: %s, Active: %b" name isActive

Output:

X: 1, Y: 2
Name: Alice, Active: true

الطريقة 2: Manual access بـ fst و snd

let nestedTuple = ((1, 2), ("Alice", true))

let x = fst (fst nestedTuple)
let name = fst (snd nestedTuple)
let isTrue = snd (snd nestedTuple)

printfn "X: %d, Name: %s, IsTrue: %b" x name isTrue

Output: X: 1, Name: Alice, IsTrue: true

Note من السلايد fst و snd بيشتغلوا بس مع tuples فيها عنصرين (2 elements).

Trace الـ fst / snd

ExpressionStepResult
fst (fst nestedTuple)fst nestedTuple = (1, 2) → fst = 11
fst (snd nestedTuple)snd nestedTuple = ("Alice", true) → fst = "Alice""Alice"
snd (snd nestedTuple)snd nestedTuple = ("Alice", true) → snd = truetrue
Analogy Pattern matching زي إنك تفتح الشنطتين مرة واحدة وتوزع كل حاجة على مكانها. fst/snd زي إنك تفتح شنطة وتدخل إيدك تجيب الصغيرة وبعدين تجيب منها حاجة، خطوة خطوة.
Trap fst/snd على tuple من 3 عناصر (زي ("Alice", 25, true)) = compile error.

8 Maps (Dictionaries)

اللي في السلايد

الـ Maps (أو dictionaries) = collections of key-value pairs، وكل key unique.

let myMap = map [("a", 1); ("b", 2); ("c", 3)]

let myMap = Map.empty.Add("a", 1).Add("b", 2).Add("c", 3)

Accessing values & ContainsKey

let value = myMap.["a"]  // Returns 1

let hasKey = myMap.ContainsKey("a")  // Returns true

Adding or Removing (بيعمل map جديدة)

let updatedMap = myMap.Add("d", 4)

let smallerMap = myMap.Remove("b")

Iterating

for (key, value) in myMap do
    printfn "Key: %s, Value: %d" key value

Output المتوقع (مترتب بالـ key): Key: a, Value: 1 · Key: b, Value: 2 · Key: c, Value: 3

Summary (آخر سلايد في الـ Maps)

  1. Map = data structure لتخزين key-value pairs.
  2. Maps immutable؛ أي تعديل بيطلّع map جديدة.
  3. بتتخزن بشكل ordered حسب الـ keys.
  4. بتسمح بـ efficient lookup by key → مفيدة لاسترجاع بيانات سريع.
Analogy الـ Map زي دليل التليفونات: الاسم (key) فريد، ورقمه (value). بتدوّر بالاسم وتطلع الرقم فورًا. ولو عايز تضيف أو تشيل، بتطبع نسخة جديدة من الدليل.
Trap بتـ access بالـ key مش بالـ index: myMap.["a"]. و Add/Remove لازم تخزّن نتيجتها.
9 Discriminated Unions (الاتحادات المميزة)

اللي في السلايد

type ApiResponse =
    | Success of data: string
    | Error of message: string
    | Timeout

let handleApiResponse (response: ApiResponse) =
    match response with
    | Success data -> printfn "Request succeeded with data: %s" data
    | Error message -> printfn "Request failed with error: %s" message
    | Timeout -> printfn "Request timed out"

let response1 = Success "User data loaded"
handleApiResponse response1  // Output: Request succeeded with data: User data loaded

cont. (باقي الأمثلة)

let response1 = Success "User data loaded"
let response2 = Error "Network error occurred"
let response3 = Timeout

handleApiResponse response1
handleApiResponse response2
handleApiResponse response3

Output:

Request succeeded with data: User data loaded
Request failed with error: Network error occurred
Request timed out

الشرح

  1. الـ Discriminated Union (DU) = type قيمته تكون واحدة بس من عدة cases محددة. كل case ممكن يشيل data (Success of data: string) أو لا (Timeout).
  2. كل case بيبدأ بـ |. الكلمة of بعدها نوع الـ data اللي الـ case بيحملها.
  3. بنعمل قيمة بكتابة اسم الـ case: Success "User data loaded" أو Timeout.
  4. بنتعامل مع الـ DU بـ pattern matching: كل case له فرع، والـ data بتتربط بـ variable (Success data -> … data).
  5. في المثال التاني الـ parameter من غير annotation (response)، والـ compiler استنتج النوع من الـ cases (type inference).
Analogy الـ DU زي نتيجة الطلب في التوصيل: يا إما "اتسلّم ومعاه الإيصال" (Success + data)، يا إما "فشل ومعاه السبب" (Error + message)، يا إما "اتأخر" (Timeout بدون تفاصيل). مفيش حالة رابعة.
Exam tip لو نسيت case في الـ match الـ compiler بيحذّرك (incomplete pattern matches). ده من أكبر مميزات الـ DU: تضمن إنك غطّيت كل الحالات.
10 Functions — Inline functions

اللي في السلايد

الـ inline بيسمح للـ compiler يستبدل استدعاء الدالة بجسم الدالة (function body) وقت الـ compile. ده ممكن يحسّن الـ performance، خصوصًا لو الدالة صغيرة ومتنادى عليها كذا مرة، لأنه بيتفادى overhead استدعاء الدالة.

let inline add x y = x + y

let result1 = add 3 5
let result2 = add 10.0 5.0

Results: result1 = 8 (int) · result2 = 15.0 (float).

Activity: Create inline functions for basic arithmetic operations.

let inline sub x y = x - y
let inline mul x y = x * y
let inline div x y = x / y
Analogy بدل ما تكلّم عامل يجيب لك "ملح" كل مرة (استدعاء)، بتحط علبة الملح على الترابيزة (الـ body مكانه مباشرة) فمفيش رحلة رايح جاي.
Bonus الـ inline هنا خلّى add تشتغل على int و float مع بعض، لأن الـ + بيتحل في كل مكان استدعاء حسب النوع.
11 Higher-Order Functions

اللي في السلايد

Higher-order functions = دوال بتاخد دوال تانية كـ parameters أو بترجّع دوال كنتيجة. ميزة قوية في الـ functional programming بتدّي كود أكثر abstraction وإعادة استخدام (reusable).

Key Concepts: (1) Passing functions as arguments (2) Returning functions from functions.

1) Passing Functions as Arguments

الدالة applyTwice بتاخد function وقيمة، وتطبّق الـ function على القيمة مرتين.

let applyTwice f x = f (f x)

// A simple function to increment a number
let increment x = x + 1

// Using the higher-order function
let result = applyTwice increment 5
printfn "Result of applying increment twice: %d" result  // Output: 7

Trace: applyTwice increment 5 = increment (increment 5) = increment 6 = 7.

2) Returning Functions from Functions

let makeMultiplier factor =
    fun x -> x * factor

// Create a function that doubles its input
let double = makeMultiplier 2

// Using the returned function
let result = double 10
printfn "Result of doubling 10: %d" result  // Output: 20

Trace: makeMultiplier 2 بترجّع fun x -> x * 2 → double 10 = 10 × 2 = 20.

Analogy applyTwice زي مدير بيقول لموظف: "اعمل المهمة دي مرتين" — المهمة نفسها (الـ function) بتتبعت كـ input. makeMultiplier زي مصنع بيطلّع ماكينات: تدّيه "2" يطلّعلك ماكينة تضاعف، تدّيه "3" يطلّعلك ماكينة بتثلّث.
Trap الـ f (f x) الأقواس مهمة؛ من غيرها هتتفهم غلط.
12 Anonymous Functions & Lambda Expressions

اللي في السلايد

Anonymous functions أو lambda expressions = دوال معرّفة من غير اسم. بتتستخدم للمهام قصيرة المدى وممكن تتعرّف inline في المكان اللي محتاجها فيه، فمناسبة لما تحتاج function مرة واحدة بس.

Syntax

fun parameter1 parameter2 -> expression

بنستخدم الكلمة fun + الـ parameters + -> + الـ expression.

Example

// Defining an anonymous function to add two numbers
let add = fun x y -> x + y

// Using the anonymous function
let result = add 5 7
printfn "Result of adding 5 and 7: %d" result  // Output: 12

Use Cases in Collections

مفيدة جدًا مع List.map و List.filter و List.fold لتنفيذ عمليات على الـ lists.

let numbers = [1; 2; 3; 4; 5]

// Using an anonymous function with List.map
let squares = List.map (fun x -> x * x) numbers

printfn "Squares: %A" squares  // Output: Squares: [1; 4; 9; 16; 25]

الشرح

  • List.map f list بتطبّق الدالة f على كل عنصر وتطلّع list جديدة بنفس الطول.
  • هنا f هي fun x -> x * x (تربيع). النتيجة: 1², 2², 3², 4², 5² = [1; 4; 9; 16; 25].
  • بنطبع بـ %A لأن النتيجة list.
  • الـ lambda ملهاش اسم (fun x -> x * x)، ولما بنكتب let add = fun x y -> x + y بنديها اسم بإننا نربطها بـ add.
Analogy الـ lambda زي كوباية بلاستيك لمرة واحدة: تستخدمها في الحفلة وترميها. الدالة المسماة زي كوباية في البيت ليها مكان واسم.
Memory trigger الكلمتين المدوّرتين في السلايد: fun و ->.
13 Partial Application & Currying
let add x y = x + y
let add5 = add 5

let result1 = add5 10  // 15
let result2 = add5 20  // 25

printfn " %d, %d" result1 result2

Output: 15, 25

الشرح

  • Partial application = تنادي دالة بـ جزء من الـ arguments بس، فترجعلك دالة جديدة مستنية الباقي. add 5 لسه محتاجة y، فهي دالة.
  • Currying = في F# الدالة اللي بتاخد أكتر من argument هي فعليًا سلسلة دوال كل واحدة بتاخد argument واحد. عشان كده add 5 ينفع.
  • add5 = دالة "زوّد 5"؛ add5 10 = 15 و add5 20 = 25.
Analogy زي ما تقول للمحل "أنا عايز باقة بـ 5 جنيه" وتسيب الباقي: المحل بيعمل لك "عرض ثابت 5"، وكل مرة تيجي تقول الرقم التاني (10 أو 20) وهو يجمعه على الـ 5.
Trap الـ printfn في السلايد مكتوب " %d, %d" وفيه مسافة في الأول، فالـ output بيبدأ بمسافة.
Connection ده مرتبط بـ Higher-order: add 5 بترجّع function.

🧾 Phase 2 — Smart Summary

Types Overview

  • Basic: int, float, String, bool
  • Compound: List, Array, Tuple, Set, …
  • Print any type: printfn "%A"
  • printfn = new line · printf = no new line

Array vs List

  • Array: fixed-size, same type [| 1; 2 |]
  • List: flexible-size, linked list [1; 2]

Set

  • Unique elements, unordered (per slide)
  • set [1; 2; 3]
  • .Add(5) · .Remove(3) · .Contains(2)
  • Returns new set / bool

Record

  • Named fields, types can differ
  • type Person = { Name: string; Age: int }
  • { Name = "Ali"; Age = 25 }

Tuple

  • Ordered, fixed count, no names
  • Simple · Mixed · Nested
  • Destructure: let (d, m, y) = date
  • fst/snd = 2 elements only
  • Pattern matching = best for nested

Tuple vs Record

  • Tuple: small, simple (coords, RGB)
  • Record: complex, named (Person)

Map

  • Key-value, unique keys
  • map [("a",1); …] · myMap.["a"] · ContainsKey
  • Immutable, ordered by key, fast lookup
  • Add/Remove → new map

Discriminated Union

  • One of several cases (|)
  • Success of data: string
  • Used with match

Inline function

  • let inline add x y = x + y
  • Body replaces call at compile time
  • Faster for small, frequently called

Higher-order

  • Takes function or returns function
  • applyTwice increment 5 = 7

🎯 Phase 5 — Rapid Revision

📄 1-Page Ultra-Fast Sheet

  • Basic types: int, float, String, bool · Compound: List, Array, Tuple, Set, … · print any: printfn "%A" · printfn = new line.
  • Array [| 1; 2; 3; 4 |] = fixed-size, same type · List [1; 2; 3; 4] = flexible-size, linked list.
  • Set = unordered, unique · set [1; 2; 3; 4] · .Add(5) .Remove(3) .Contains(2) (true) / (7) (false).
  • Record = named fields (types may differ): type Person = { Name: string; Age: int; Job: string }.
  • Tuple = ordered, fixed count: simple (3, 5), mixed ("Alice", 25, true), nested ((1, 2), ("Alice", true)). fst/snd only for 2 elements; pattern matching best.
  • Tuple vs Record: tuple = no names (coords, RGB) · record = named (Person).
  • Map = key-value, unique keys, immutable, ordered by key, fast lookup · .["a"] · ContainsKey · Add / Remove → new map.
  • DU = one of several cases: Success of data: string | Error of message: string | Timeout + match.
  • Inline = compiler replaces call with body · Higher-order = takes or returns function · Lambda = fun x y -> x + y · Partial application = add 5.
