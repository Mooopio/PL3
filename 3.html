1 · Functional programming & F#

Functional programming builds programs from functions, immutable values and transformations. F# is statically typed, expression-oriented, in the ML family.

Analogy: a spreadsheet formula — you describe how a result is derived from inputs; you don’t step through commands.
let square x = x * x
let message = sprintf "Square is %d" (square 5)
printfn "%s" message // Square is 25
2 · Immutability, mutation, shadowing

let bindings are immutable by default. let mutable allows reassignment using <-. A second let with the same name makes a new binding (shadowing), not mutation.

let x = 10
let y = x + 5
let mutable counter = 0
counter <- counter + 1
let x = x + 5  // shadowing; valid
Analogy: shadowing = a new name tag on a new box; mutation = changing what’s inside the same box.
Trap: = binds/compares; <- assigns. y stays 15 after shadowing x.
3 · Pure functions

A pure function has no observable side effects and returns the same result for the same inputs. Impure functions depend on or change external state. Pure expressions give referential transparency (an expression can be replaced by its value).

let add a b = a + b // pure
let mutable total = 0
let addToTotal x =
    total <- total + x
    total // impure
4 · Pattern matching & discriminated unions

match ... with selects by value or structure. Guards use when; _ is the wildcard. Works on tuples, lists and unions; the compiler warns on incomplete cases.

let describeValue input =
    match input with
    | 0 -> "Zero"
    | n when n < 0 -> "Negative"
    | _ -> "Positive"
type Shape =
    | Circle of float
    | Rectangle of float * float
let area = function
    | Circle r -> System.Math.PI * r * r
    | Rectangle (w,h) -> w * h
A discriminated union = “one of several named shapes of data”. Each case can carry different data.
5 · Recursion & tail recursion

A recursive function calls itself and needs a terminating base case. Tail recursion: the recursive call is in the final position, enabling optimization in suitable circumstances. The accumulator acc carries the running result.

let rec factorial n =
    if n = 0 then 1
    else n * factorial (n - 1)
let factorialTR n =
    let rec loop acc n =
        if n <= 1 then acc
        else loop (acc * n) (n - 1)
    loop 1 n
In factorial, n * factorial (n-1) is NOT a tail call: a multiplication remains after the call returns.
6 · Higher-order functions

Functions that accept or return functions. List.map transforms, List.filter selects, List.fold accumulates, List.map2 combines corresponding elements of equal-length lists.

[1..5] |> List.map (fun x -> x*x)        // [1;4;9;16;25]
[1..10] |> List.filter (fun x -> x % 2 = 0) // [2;4;6;8;10]
[1..5] |> List.fold (+) 0                 // 15
List.map2 (+) [1;2;3] [4;5;6]             // [5;7;9]
7 · Composition & pipelines

>> composes left to right; << right to left. |> feeds a value into a function.

let double x = x * 2
let increment x = x + 1
let f = double >> increment
f 3 // 7
[1..10] |> List.filter (fun x -> x % 2 = 0)
        |> List.map (fun x -> x*x)
        |> List.sum // 220
Analogy: an assembly line — each station (function) hands its output to the next.
8 · Lazy evaluation & sequences

F# is normally strict, but lazy values compute only on Force(). Sequences produce elements on demand, even infinite streams.

let lazyValue = lazy (printfn "Computed"; 2 + 2)
let result = lazyValue.Force()
let naturals = Seq.initInfinite id
naturals |> Seq.take 5 |> Seq.toList // [0;1;2;3;4]
9 · Declarative & parallel processing

Declarative pipelines describe what, avoiding manual mutable loops. Array.Parallel.map processes independent elements across available cores.

open System.IO
let total =
    File.ReadAllLines("data.txt")
    |> Array.map int
    |> Array.filter (fun x -> x > 50)
    |> Array.sum
let squares = [|1..1000|] |> Array.Parallel.map (fun x -> x*x)
10 · Computation expressions

Structure specialized workflows. The async builder supports asynchronous computations; let! binds the result of an async operation. An option builder needs a library or your own definition.

open System.Net.Http
let fetchData url = async {
    use client = new HttpClient()
    let! content = client.GetStringAsync(url)
                   |> Async.AwaitTask
    return content.Length
}
11 · Imperative vs functional

Imperative: statements + mutable state. Functional: expressions, transformations, recursion, immutable values. F# supports both styles.

Smart Summary

  • F# = static, expression-oriented, ML family
  • Values: let immutable → let mutable + <- → same name again = shadowing
  • Pure = no side effects + same in → same out → referential transparency
  • Match: when guard, _ wildcard, unions, incomplete = warning
  • Recursion: base case; tail = call in last position (accumulator)
  • HOFs: map, filter, fold, map2 (equal lengths)
  • Operators: >> L→R, << R→L, |> pipe
  • Lazy: Force(); Seq on demand (infinite OK)
  • Parallel: Array.Parallel.map for independent items
  • Async: async { let! ... }; option builder needs a library

Written Questions

Short: Explain shadowing vs mutation.

Shadowing re-declares a name with let, creating a new binding; the old value is unchanged. Mutation needs let mutable and <-, and changes the same binding. Example: let x = x + 5 vs counter <- counter + 1.

Short: What makes a function pure? Give an example.

No observable side effects and the same output for the same inputs, so it is referentially transparent. add a b = a + b is pure; addToTotal changes external mutable total, so it is impure.

Short: Why use tail recursion?

The recursive call is the last action, so it can be optimized in suitable circumstances. factorialTR uses an accumulator, unlike factorial, which multiplies after the call returns.

Long: Trace [1..10] |> List.filter even |> List.map square |> List.sum.

Filter keeps [2;4;6;8;10]. Map squares them: [4;16;36;64;100]. Sum = 220. Pipelines read top to bottom, avoid mutable loops, and are declarative.

Long: Compare imperative and functional styles; where do lazy evaluation and async help?

Imperative uses statements and mutable state; functional uses expressions, transformations, recursion and immutable values; F# supports both. Lazy evaluation delays work until Force() and sequences can model infinite streams (Seq.initInfinite + Seq.take). Async workflows use let! to bind results of asynchronous operations (e.g. HTTP) without blocking. Declarative pipelines can also use Array.Parallel.map for independent elements.
